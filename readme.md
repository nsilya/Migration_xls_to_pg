# Оптимизация миграции данных из Excel в PostgreSQL 

1. **Автоматизированная оценка совместимости** — валидация структуры и содержания данных до переноса.
2. **Параллельная обработка с маркировкой** — каждая строка помечается флагом `processed = TRUE` после успешной обработки.
3. **Промежуточное хранилище** — данные проходят через PostgreSQL перед загрузкой в целевую систему.

## Функционал

- Чтение данных из Excel (имитация легаси-системы без API)
- Валидация корректности дат
- Запись валидных записей в PostgreSQL
- Маркировка обработанных строк в исходном файле
- Логирование ошибок в файл `migration_errors.log`

## Требования

- Python 3.8+
- PostgreSQL 12+
- Пакеты: `pandas`, `openpyxl`, `psycopg2-binary`, `python-dateutil`

## Запуск

1. Создайте базу данных и пользователя:
   ```sql
   CREATE DATABASE migration_db;
   CREATE USER migrator WITH PASSWORD 'securepass123';
   GRANT ALL PRIVILEGES ON DATABASE migration_db TO migrator;
   ```

2. Убедитесь, что PostgreSQL запущен и доступен на `localhost:5432`.

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Сгенерируйте тестовые данные:
   ```bash
   python generate_excel.py
   ```

5. Запустите миграцию:
   ```bash
   python rpa_migration_bot.py
   ```

## Проверка результата

После выполнения:

- Валидные записи находятся в таблице `migrated_data`:
  ```bash
  psql -h localhost -U migrator -d migration_db -c "SELECT * FROM migrated_data LIMIT 5;"
  ```

- Ошибки записаны в `migration_errors.log`.

- Исходный файл `source_data.xlsx` обновлён: обработанные строки имеют `processed = TRUE`.

## Архитектура

Сценарий соответствует промышленному подходу к миграции:
```
Источник (Excel) → Валидация → Промежуточное хранилище (PostgreSQL) → Целевая система
```
